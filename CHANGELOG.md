# Changelog

## 0.2.0-preview — 2026-09-15

- Native Windows preview with local streaming chat, installed models, Windows speech, local recognition, editable memory and an avatar view.
- Windows per-user installer and portable ZIP; automated frozen-app/install/uninstall checks.
- Public repository, round portrait branding, actual custom-avatar screenshot and clear platform-specific setup instructions.
- Linux fresh-install prompts no longer assume the original owner’s name/hardware; existing production installation remains untouched.


## 0.1.0-preview — 2026-09-14

First packaged Linux preview: native desktop companion, local adaptive models,
continuous conversation, SSD memory, bounded everyday tools, source installer,
private-data exclusions and NAS restoration support.

Includes corrected27B preloading and separate model/reasoning selection.
Experimental prompt compression was rejected after an accuracy regression;
the full instructions remain. NPU/GPU split inference is not enabled.
