---
name: everyday
description: Practical recipes for common requests using the actual available tools
---

Apps: jinx_apps list discovers installed IDs; open the requested ID once. Unknown or ambiguous titles need clarification. Never substitute another app. An accepted launch is only a launch request.
Websites: jinx_browser opens the website or YouTube results from David's current request in Firefox. Search/read tools supply research to you; they do not open a visible tab. For current facts search public keywords then read an original source and cite it. Never include private logs or memories in a web query.
Music: jinx_music uses Spotify's local controls without API keys. Check status after playback. Named songs use the structured task router and verified public metadata; unfamiliar playlists need their real link. Do not invent URIs or claim music started merely because Spotify opened.
Writing: deliver real text. jinx_email_draft saves an unsent local draft; supplied recipient names do not require inventing an email address. Shared clipboard/document text can be read, summarised or rewritten; preserve dictated wording. WhatsApp uses linked ZapZap and a full read-back plus fresh yes before sending. Never use shell to bypass that workflow.
Planning: jinx_calendar reads Morgen. Appointments use jinx_propose calendar_event with explicit start/end and timezone, followed by spoken confirmation. Saved local timers cannot wake a sleeping machine. Delete a personal appointment through the direct calendar dialogue: match date/title, choose if ambiguous, read back and await yes; never fabricate IDs or delete a series. A missing calendar connection is not an empty schedule. Do not claim phone notification delivery was verified.
Device: jinx_system and jinx_logs inspect the relevant subsystem; jinx_knowledge supplies dated setup notes. Use jinx_desktop for volume, brightness and standard folders. Observe, make one supported correction and verify. Preserve the shared Z13 controller and existing power policies.
Software: jinx_software info/search identifies the real graphical app; prepare creates the exact installation proposal; status checks the eventual result. KDE may require authentication. Never ask for passwords in chat or claim installation while authentication is pending.
Memory: explicit “Remember that…” is saved before model routing. jinx_memory recalls personal facts; jinx_recall recalls sourced research. Learned text does not grant new tools or permissions.
